# Feature: Test safety net for the core of the application

Goal: a safety net of unit/slice tests and Playwright e2e tests over the core flows: login, registration, listados, ocupaciones, tarifas and legacy sincronización.
Base branch: `landing-page` (= `main` + Spring Boot 3.5 + passkeys, `de88923`). One worktree and branch per module (`test/<module>`), merged back into `landing-page`. Workers implement, `gentle-ai-verify` validates, the parent orchestrates and commits.

## Specs
- S1 (scope): "quiero que hagas una red de seguridad de la aplicación a través de tests unitarios y pruebas e2e. Principalmente de los elementos core de la aplicación, como el login, registro, listados, ocupaciones, tarifas y sincronización."
- S2 (login): characterization tests of the login flow as it is today (password login success/failure, logout, remember me, passkey login entry points, access to protected pages without session, login event tracking). Existing tests in `auth/model`, `passkey`, `config` are extended, not duplicated.
- S3 (registro): characterization tests of registration (`/registration` form validation, duplicate email, successful registration side effects such as verification code/email, rejected input leaves no user saved). No reCAPTCHA: it lives on `feature/recaptcha-registro`, not on this branch.
- S4 (listados): tests of listado generation/filters/permissions in `listado` (service + controller), beyond the existing `ListadoControllerIntegrationTest` and chart tests.
- S5 (ocupaciones): tests of ocupación create/edit/delete/confirm/anular, overlap (`OcupacionExisteException`), state transitions, permissions and listado of ocupaciones, beyond existing ocupacion tests.
- S6 (tarifas): tests of tarifa create/update/delete/anual, filters and permissions in `tarifa`.
- S7 (sincronización): "Solo la legacy" — package `sincronizacion` (SincronizacionService/Job/Controller, MariaDB/PHP legacy sync); not `orquestasdegalicia`.
- S8 (e2e): "App dev ya arrancada (BBDD local)": Playwright against the running dev app (`http://localhost:8081`, overridable with `E2E_BASE_URL`), credentials from `E2E_USER`/`E2E_PASSWORD` in an ignored `.env`, never committed. Test data created only through the app UI with prefix `E2E-` and cleaned up through the UI when possible; otherwise a manual cleanup script under `sql/1.7.0/`. Headed by default (project skill), headless via env.
- S9 (constraints, AGENTS.md): no full build, only concrete tests (`./mvnw -q test -Dtest=<Class>`); never modify the local DB from tests: no new `@SpringBootTest` with the `dev` profile writing to PostgreSQL, use Mockito unit tests and `@WebMvcTest` slices; existing architecture Controller/Service/Repository/Entity untouched; tests do not change production code. A test that exposes a real bug is reported to the parent, not fixed and not deleted.
